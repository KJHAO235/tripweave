# TripWeave

TripWeave 是一個旅程重建工具，目標是在 iPhone 上使用，可以把 GPS 軌跡和照片做成地圖動畫。

和 Relive 最大的不同是「重建」：遇到隧道、訊號中斷、飛機等情況，不會直接拉成直線，而是推測當時的交通方式，沿著鐵路、道路或航線補齊，並清楚標示哪些路段是推算出來的。

## 目前進度

開發中。已完成：

- 匯入 GPS 軌跡（KML、GPX），可一次選取多個檔案合併成一趟旅程（例如一天一個檔案）
- 在地圖上顯示軌跡，找出訊號中斷造成的缺口
- 搭火車時訊號中斷的路段，自動沿實際鐵路補齊（全球鐵路資料，來自 OpenStreetMap），並以不同樣式標示為推算
- 搭飛機時沒錄到的航段（依速度或距離判斷），以大圓航線補齊並標示為「推算（飛機）」
- 旅程自動保存在手機上（不會上傳），開啟時回到上次的旅程；可以有多趟旅程，切換、改名、刪除（可復原）
- 已開啟的旅程可以再加入檔案（相同檔案自動略過）或移除其中的檔案

## 預計功能

- 補齊其他交通方式的缺口（渡輪等）；飛機對應到實際機場
- 匯入/選取旅程照片
- 自動產生路線 + 照片的地圖動畫
- 輸出/分享動畫影片

## 技術

- 網頁 PWA，在 iPhone Safari 開啟並「加入主畫面」使用
  - 旅程只存在這支手機的這個 App 裡（瀏覽器的 IndexedDB）。建議從主畫面開啟；在 Safari 分頁中使用且長期未開啟時，iOS 可能會清除網站資料
- Vite + React + TypeScript
- 地圖：MapLibre GL JS + OpenFreeMap 圖磚
- 部署：GitHub Pages

## 開發

需要 Node.js 24 以上。

```sh
npm install       # 安裝依賴
npm run dev       # 啟動開發伺服器
npm test          # 執行測試
npm run build     # 建置正式版本到 dist/
```

測試資料放在 `test-data/`。
