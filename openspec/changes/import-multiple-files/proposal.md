# Proposal

## Why

使用者的紀錄是一天一個檔案（例如 Relive 的「日本四極點」共 15 天），目前一次只能匯入一個檔案，看不到整趟旅程。實測 Relive 下載的 GPX 也發現：沒錄到的飛機航段會落在「兩天的檔案之間」，必須先把同一趟旅行的檔案合在一起，才能看到並在之後補上這類缺口。

## What Changes

- 「匯入軌跡」可以一次選取多個檔案（KML、GPX 可混用），合併成一趟旅程；仍然只有一個按鈕
- 檔案依時間先後排列；沒有時間資料時依檔名的自然順序（Day2 排在 Day10 前面）
- 部分檔案無法匯入時，其餘檔案照常匯入，並列出失敗的檔案與原因
- 讀取多個檔案時顯示進度
- 兩個檔案之間的空白和其他缺口一樣被偵測、自動嘗試沿鐵路補齊，並在缺口列表標示為「檔案之間」
- 畫面顯示旅程的檔案數與日期範圍
- 再次匯入時取代目前的旅程（不提供「加入檔案」等額外按鈕）

不在本次範圍：飛機航線補齊（下一個 change）、時間重疊的檔案去重、匯入紀錄的保存。

## Capabilities

### New Capabilities
（無）

### Modified Capabilities
- `track-import`：新增一次匯入多個檔案並合併；修改「無法匯入時提供明確訊息」以處理部分失敗
- `gap-detection`：新增跨檔案缺口的標示
- `track-map-view`：新增多日旅程的顯示效能要求

## Impact

- `src/core`：軌跡段落記錄來源檔案、合併多個檔案的軌跡
- `src/components/ImportButton.tsx`、`App.tsx`：多選、讀取進度、部分失敗訊息
- 測試資料新增兩個 Relive GPX（2024/8/14、8/15，與現有 `Day1+2.kml` 同一趟旅程，含逐點時間）
