# Spec Delta

## ADDED Requirements

### Requirement: 標示檔案之間的缺口
來自不同檔案的相鄰點之間形成的缺口，系統 SHALL 標示為「檔案之間」，與同一檔案內的缺口區分；其偵測、補齊方式與其他缺口相同。

#### Scenario: 前一天的終點與隔天的起點相近
- **WHEN** 合併 2024/8/14（終點在札幌）與 8/15（起點在札幌）兩個 GPX，兩點相距約 0.1 km
- **THEN** 兩個檔案之間不形成缺口

#### Scenario: 兩個檔案相隔很遠
- **WHEN** 合併的兩個檔案，前一個的終點與後一個的起點相距 200 km
- **THEN** 該處形成一個缺口，並在缺口列表與缺口資訊中標示「檔案之間」
