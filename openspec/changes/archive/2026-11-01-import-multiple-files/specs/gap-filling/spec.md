# Spec Delta

## MODIFIED Requirements

### Requirement: 匯入後自動補齊
系統 SHALL 在軌跡匯入並完成缺口偵測後，自動對每個缺口嘗試補齊，不需要使用者按任何按鈕或做任何選擇。軌跡與缺口 MUST 先顯示，補齊在背景進行，補齊的結果陸續更新到畫面，至少每秒更新一次，不必等全部完成。

#### Scenario: 匯入後不需操作即開始補齊
- **WHEN** 使用者匯入 `Day1+2.kml`
- **THEN** 軌跡與缺口立即顯示，接著在沒有任何操作的情況下，苫小牧到札幌的缺口被補齊

#### Scenario: 補齊期間可以正常操作
- **WHEN** 補齊仍在進行中
- **THEN** 使用者可以平移縮放地圖、查看缺口列表，畫面上有簡短的進度提示

#### Scenario: 多日旅程陸續顯示補齊結果
- **WHEN** 匯入 14 天的旅程，共數百個缺口
- **THEN** 補齊過程中「已補齊」的數量與地圖上的推算路段持續增加，而不是全部完成後才一次出現
